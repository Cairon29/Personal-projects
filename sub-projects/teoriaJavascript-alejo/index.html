Datos primitivos

Number

Es un tipo de dato numérico, ya sea enteros o de punto flotante, la forma en la cual se declara esta variable es la siguiente: Cualquier parámetro pasado al new Number() que no sea un número (por ejemplo, la "A"), dará como resultado un valor NaN (Not A Number).

String

se utiliza para representar cadenas de textos, en donde cada elemento en el string ocupa una posición en la cadena. En el caso de Js las cadenas de texto son inmutables (una vez que se crean ya no es posible modificarlas), Para englobar los textos, se pueden utilizar tres tipos de comillas comillas simples ('), comillas dobles ("), Backticks (`)

Boolean

Es un tipo de dato el cual puede tener alguno de estos dos calores posibles: true, false. El cual se utiliza para representar estados lógicos o condiciones como la respuesta a una afirmación, la veracidad de una prueba o el resultado de una comparación.

Undefined

representa la ausencia del valor o la inicialización de una variable. Es el valor asignado automáticamente a una variable que ha sido declarada, pero que no ha sido inicializada con un valor explícito. No debe confundirse con Null, que es otro valor que indica la ausencia de valor, pero con una semántica diferente.

Null

representa una referencia que apunta, a una inexistente o invalido objeto o dirección. En otras palabras, es un valor nulo o “vacío”

Symbol

Es un objeto incorporado para añadir claves de propiedades únicas a un objeto que no sean iguales a las claves que cualquier otro código pueda añadir al objeto, y que están ocultas de cualquier mecanismo que otro código utilice normalmente para acceder al objeto

BigInt

Es un dato numérico el cual representa los números enteros con más “precisión” o más extensa.

Condicionales if

Evalúa una condición y ejecuta un bloque de código si la condición es verdadera (if), si es falsa otra condición será ejecutada (else) También puede a ver sentencias con múltiples selecciones, La estructura else if se usa cuando hay más de dos posibles casos. Se evalúan las condiciones de arriba hacia abajo y se ejecuta solo el primer bloque cuyo if o else if sea verdadero

  • Bucle for – Para repeticiones con un número determinado de iteraciones.
  • Bucle while – Se ejecuta mientras una condición sea verdadera.
  • Bucle do...while – Similar a while, pero siempre se ejecuta al menos una vez.

FOR

repite hasta que una condición especificada se evalúe como false

DO WHILE

La instrucción do...while se repite hasta que una condición especificada se evalúe como falsa. Si condición es true, la declaración se ejecuta de nuevo. Al final de cada ejecución, se comprueba la condición. Cuando la condición es false, la ejecución se detiene y el control pasa a la declaración que sigue a do...while.

Funciones

Un método o función con parámetros es una función que recibe valores, llamados parámetros, para realizar una tarea específica. Los parámetros permiten que una función sea reutilizable, ya que puede ejecutarse con diferentes datos según sea necesario. Cuando se llama a la función, se pasan los valores (argumentos) en el mismo orden en que fueron definidos los parámetros.
